# 📊 Sprint 3: Technical Indicators Engine

> **الحالة:** مكتمل بنجاح ✅  
> **الهدف:** بناء محرك حسابي نقي ومستقل (Domain Pure Functions) لحساب المؤشرات الفنية الأساسية (SMA, EMA, RSI, MACD) بدقة مالية متناهية باستخدام `Decimal`، وتوفير أمر فحص تفاعلي `forex analyze` عبر سطر الأوامر.

---

## 🏗️ القرارات الهندسية والمعمارية (Architecture Decisions)

1. **Pure Domain Calculations (دون اعتماديات خارجية):**
   * حساب المؤشرات مباشرة دون الاعتماد على مكتبات إضافية مثل `pandas-ta` أو `TA-Lib`، التزاماً بمبدأ YAGNI وخفة المشروع وسهولة نقله لأي بيئة.
   * الحفاظ على دقة `Decimal` لتفادي أخطاء الفاصلة العائمة (Floating Point Arithmetic).

2. **عقد المؤشرات الموحد (`BaseIndicator`):**
   * جميع المؤشرات تنفذ دالة `calculate(candles: list[Candle]) -> list[IndicatorResult]`.
   * إرجاع قائمة نتائج مطابقة زمنياً لنفس تسلسل الشموع؛ حيث تكون قيم الفترات غير المكتملة مساوية لـ `None`.

3. **حسابات الزخم المتقدمة:**
   * **Wilder's Smoothing في RSI:** الحساب المعتمد في الأسواق المالية وليس الـ SMA البسيط لتنعيم مؤشر القوة النسبية.
   * **الهيكل الكامل لـ MACD:** استخراج خط الماكد، خط الإشارة الأسي (EMA-9)، والهيستوجرام كفرق بينهما.

4. **تكامل طبقة العرض والخدمة:**
   * تحديث `ForexService.analyze_pair()` لربط القراءة من SQLite بحسابات المؤشرات.
   * صياغة تقرير تحليلي يفسر إشارات التشبع الشرائي والبيعي والزخم اللحظي في أمر `forex analyze`.

## 💻 الأوامر المضافة في الـ CLI

```bash
# 1. تحليل الشموع اليومية الافتراضية
forex analyze --pair EUR/USD --interval 1day

# 2. تحديد مؤشرات معينة وعدد شموع محدد
forex analyze --pair GBP/USD --interval 1h --indicators sma,rsi --limit 40
